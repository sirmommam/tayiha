# ทายฮา

เกมทายชื่อจากอีโมจิ ภาษาไทย

หมวด: หนังดัง, ผลไม้, ของใช้, กีฬา, อาหาร, ของในบ้าน, เครื่องดื่ม หรือสุ่มทุกหมวด

- สุ่ม 10 ข้อต่อรอบ
- เลือกเวลาทั้งรอบได้ 30 / 60 / 90 / 120 วินาที
- ตอบถูก +100 คะแนนความเร็วสูงสุด +80 (ภายใน 8 วินาที) และโบนัสตอบถูกติดกัน
- สรุปคะแนนหลังจบ พร้อมเฉลยทุกข้อ
- จำสถิติสูงสุดไว้ในเครื่อง

```bash
npm install
npm run dev
```
